# SafeCall


- **backend**:後端服務（FastAPI，多服務容器化：auth/chat/fraud/push_notification）
- **edge**：邊緣裝置（執行 VoIP/AI 辨識的 Python + aiortc 硬體設備）
- **frontend**：使用者裝置 App（kebbi 或長者的手機，Flutter）
- **host_node (sim card phone)**：模擬主機的 SIM 卡手機（簡易版 whoscall UI）
